Aurora — word-level blur · mini card preview

Browser preview of the Kotlin law in app.aurora.player.spike.KaraokeLine / designsystem/Components.kt (AuroraLyricPreviewBox). Each word starts blurred and faint, then sharpens as it is sung: blurProgress = (now − wordStart) / (wordEnd − wordStart), blurRadius = maxPx × (1 − progress), alpha = progress. The effect is used only in the mini card (WORD_BLUR_MAX_PX = 8); the full lyric panel stays plain text, exactly as it ships. CSS filter: blur() here is only a browser stand-in for the Android 4-pass stroke halo — the shipped effect draws strokes, not a filter. Timing below is simulated (no audio clock in a browser); on Android, now is Rust's audio-clock positionMs.
